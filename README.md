# OSCA — сайт продажи 3D-персонажей для стримеров

Тёмный неоновый лендинг с **интерактивным 3D-просмотрщиком** персонажей (Three.js / WebGL).
Персонажи собираются процедурно из примитивов прямо в браузере — модель можно крутить мышью,
зумить колесом и переключать между 8 стилями в галерее.

> ⚠️ Нужен **доступ в интернет** — Three.js подключается с CDN.
> ⚠️ Нужен **WebGL** в браузере (включен по умолчанию).

## Управление 3D
| Действие | Результат |
|----------|-----------|
| Перетаскивание мыши  | вращение модели |
| Колесо / щипок (тач) | зум |
| Клик по карточке     | смена персонажа в просмотрщике |
| Кнопки в просмотрщике | сброс, авто-вращение, частицы |

## Как добавить своего персонажа
1. Скопируйте блок в `assets/js/characters.js` → массив `OSCA`.
2. Задайте `id`, `name`, `emoji`, цвета (`skin`, `accent`, `eye`, `secondary`),
   тип `style` (`cat`, `antenna`, `halo`, `hat`, `fox`) и `material`.
3. Сама 3D-модель соберётся автоматически в `viewer.js`.
